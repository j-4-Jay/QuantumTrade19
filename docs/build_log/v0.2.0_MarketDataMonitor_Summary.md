## Delivered Architecture

Tier 2 `MarketDataMonitor` now wires the Market Data Workers behind the stable public interface:

```python
get_live_candle(symbol, timeframe)
get_historical_candles(symbol, timeframe, days)
subscribe(symbol)
unsubscribe(symbol)
get_health()
```

Delivered/verified components:

- `SymbolRegistryWorker` with active symbols, Futures pair identities, tick metadata, favorites, and persistence.
- `WSFeedWorker` connected to CoinDCX's aggregated Futures channel: `currentPrices@futures@rt`.
- `CoinDCXSocketTransport` using `curl_cffi` Chrome TLS/JA3 impersonation, required by CoinDCX gateway fingerprint filtering.
- Aggregated-stream partial-delta handling: price-bearing `ls`/`mp` rows become ticks; metadata-only or absent symbol rows remain normal transport heartbeats and do not produce false tick warnings.
- `RestPollFallbackWorker` using CoinDCX Futures current-prices REST data.
- `TickNormalizerWorker` with a single normalized tick shape for downstream consumers.
- `HistoricalDataLoaderWorker` corrected to use CoinDCX **Futures** candlestick data (`pcode=f`) rather than spot data.
- Futures history query timing corrected: `from`/`to` use epoch seconds; returned candle timestamps use milliseconds.
- Futures native/derived timeframe support:
  - Native: 1m, 5m, 1H, 1D.
  - Derived: 15m from 5m; 4H from 1H; 1W/1M from UTC calendar grouping.
- UTC exchange boundaries confirmed for PDH/PDL and 4H derivation against the CoinDCX Futures terminal.
- `CandleBuilderWorker` seed/live stitching fix: last historical candle is retained as forming state, preventing the original one-time 5m/15m duplicate seam.
- Deep Historical Data extras: manifest, background downloader, depth prober, local coverage tracking, and Settings-facing ceiling/progress APIs.
- Persistent runtime logging foundation:
  - `logs/quantumtrade19.log`: all runtime events.
  - `logs/errors.log`: warnings/errors.
  - UTC timestamps, daily rotation, 30 retained log files, thread context, and unhandled thread/main exception hooks.
