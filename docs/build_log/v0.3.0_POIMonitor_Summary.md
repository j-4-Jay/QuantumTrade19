## Delivered Architecture

Tier 2 `POIMonitor` wires the five Tier 1 POI Workers behind the public interface:

```python
get_active_pois(symbol)
get_poi_state(symbol, poi_id)
set_poi_type_enabled(poi_type, enabled)
```

Delivered Workers:

1. `POILevelCalculatorWorker`
   - 1M High/Low, 1W High/Low, PDH/PDL, 4H High/Low.
   - Resistance Flip and Support Flip.
   - Uses Market Data Monitor HTF candles only; never consumes raw ticks or trading-TF setup data directly.

2. `FVGDetectorWorker`
   - Bullish/bearish 3-candle Fair Value Gap recognition.
   - Stores price range, source TF, formation index, role, direction, and stable logical ID.

3. `OrderBlockDetectorWorker`
   - Detects last opposite-colored candle before ATR-relative impulsive movement.
   - Stores bullish support / bearish resistance range POIs.

4. `InverseFVGDetectorWorker`
   - Consumes injected FVG output rather than independently re-scanning gaps.
   - First close-through records invalidation direction.
   - Opposite-direction second close-through creates the inverse FVG and flips support/resistance role according to locked 123Bull/123Bear Scenario B rules.

5. `POIStateTrackerWorker`
   - Tracks distance in ticks, `Approaching`, `Hit`, `Crossed`, `Retesting`, last touch, and crossed direction independently for each POI.

Shared support:

- `poi_types.py`: shared POI/state types, defaults, line-POI source-timeframe mapping.
- `candle_access.py`: compatibility adapter for mocked dict candles and File 02 production `Candle` dataclasses.
- `htf_availability.py`: graceful source-HTF availability probing rather than hardcoding assumptions about populated history.

## Defaults

Default strategy-active POI types:

```text
PDH / PDL
4H High / 4H Low
```

All other original File 03 types default OFF.
