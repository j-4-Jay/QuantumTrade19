## Real Bugs Found and Fixed During Batch 3 Review (Before Any Test Was Run)

Caught by cross-checking the handed-over `poi_monitor.py` against the real, current content of every Worker it wires together — not by running tests first:

1. **Missing `get_tick_size()` on `SymbolRegistryWorker`.** `POIMonitor` construction called a method that didn't exist on the real registry. First attempt to fix this (changing the call site to `get_symbol_info().tick_size`) was itself wrong — the test suite's own `FakeSymbolRegistry` test double confirmed `get_tick_size()` was always the correct, intended contract. Corrected by adding `get_tick_size()` to the real registry instead, and reverting the call site. See `DECISIONS.md` DEC-007 for the full account of this self-correction.
2. **Incomplete display-toggle propagation.** `set_poi_display_enabled()` only ever updated `_level_workers`, never the three zone workers (`FVGDetectorWorker`, `OrderBlockDetectorWorker`, `InverseFVGDetectorWorker`), which have no `set_display_enabled()` method of their own and each hold an independent `display_enabled` dict. Fixed by updating those dicts directly in `POIMonitor`, mirroring how `set_poi_strategy_enabled()` and `set_zone_source_tf_enabled()` already correctly branch across all four relevant workers.
