## Critical bugs found and fixed during this module
1. **Display/Strategy independence bug** — `is_type_ready()` and all 3 zone workers gated computation on Strategy alone, silently ignoring Display. Fixed across `poi_level_calculator_worker.py`, `fvg_detector_worker.py`, `orderblock_detector_worker.py`, `inverse_fvg_detector_worker.py`.
2. **Critical crash (chart freeze/app restart)** — `FVGDetectorWorker`/`OrderBlockDetectorWorker` passed a candle-count value into a `days` parameter, causing 60 *days* of 1m/15m candles (tens of thousands of rows) to be scanned per tick on default-ON timeframes, producing thousands of overlapping zone overlays. Fixed with a hard cap to the most recent 60 candles.
3. **Reflex background-task misuse crash** — `reset_poi_timezone_default` awaited a `@rx.event(background=True)` handler directly, which is illegal in Reflex and poisoned the session's event loop. Fixed to return the event instead.
4. **Dot pixel-placement, two false starts before the real fix** — first attempt guessed a timestamp duration offset; second attempt guessed at `getBarSpace()` field semantics and averaged two `dataIndex` conversions, overshooting by half a candle. Real fix: `convertToPixel({dataIndex, value})` already returns the candle's pixel center — use it directly, no extra math.
5. **Settings "auto-revert" illusion** — Settings page remounts on every tab switch (`key=active_tab`), re-firing `on_mount=load_poi_settings()`, which re-read a possibly-stale engine snapshot mid-async-save and stomped just-made changes. Fixed by only doing the full engine re-read once per session.
