## Identified loader conflict
Local installed react-klinecharts is 1.0.1, KLineCharts is 10.0.2. Its KLineChart.tsx invokes onReady during mount, then in a later effect installs dataLoader if provided; otherwise it replaces the manually installed QT19 loader with a static-data loader whose callback captures the data prop. QT19 previously passed data={data} and installed its own loader in onReady. Corrections updated dataRef.current and reset the chart, but that later static loader could reload the old prop array. This conflict is established by installed source and reproduced in the new executable regression model. No node_modules edits.
