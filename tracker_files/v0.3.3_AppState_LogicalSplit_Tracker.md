## Trading Panel problem

The installed `react-klinecharts` wrapper re-applies the chart when its static `data` array is replaced. Current `AppState.poll_trading_panel_chart()` calls `refresh_trading_panel_chart()` every three seconds, and that function replaces `trading_panel_candles` with a rebuilt full candle list. This is why the chart returns to the newest/live candle while the user studies historical price action. The package documentation identifies static `data` replacement separately from `dataLoader` streaming updates. [web:177]

## Required behavior

- Historical chart position must stay fixed while the user scrolls back.
- The background polling loop must update OHLC display values only; it must not replace the full chart candle array every three seconds.
- Full candle reload is allowed only when the user opens Trading Panel, changes symbol, changes timeframe, or changes Display Last X Days.
- Future chart controls must include only:
  - Show Grid / Hide Grid
  - Reset View
  - Day / Night chart theme
  - Follow Live on/off
  - Go to Live
- Do not re-add useless Candle/Bar, zoom, pan, or candle-width context-menu controls unless explicitly requested later.
