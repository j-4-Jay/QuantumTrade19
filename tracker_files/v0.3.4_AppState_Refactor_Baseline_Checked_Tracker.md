## Known Trading Panel issue

`poll_trading_panel_chart()` currently calls `refresh_trading_panel_chart()` every three seconds. That full refresh replaces `trading_panel_candles`, and the installed `react-klinecharts` wrapper reapplies its static data array. The chart therefore jumps back to the newest candle while the user is reviewing historical candles.

## Required behavior

- Keep the historical chart position unchanged while the user scrolls back.
- Background polling must update only the displayed Open, High, Low, and Close values.
- Background polling must never replace the full `trading_panel_candles` list every three seconds.
- Full candle-array reload is allowed only when the user opens Trading Panel, changes symbol, changes timeframe, or changes Display Last X Days.
- Keep the boundary: MarketDataMonitor -> AppState -> UI.
- The UI must never call CoinDCX directly.
- Do not manually edit `.web`.

## Required chart controls

Implement only these real controls after viewport persistence is fixed:

- Show Grid / Hide Grid
- Reset View
- Day / Night chart theme
- Follow Live on/off
- Go to Live

Do not add Candle/Bar switching, zoom, pan, candle-width, or other context-menu controls unless explicitly requested later.
