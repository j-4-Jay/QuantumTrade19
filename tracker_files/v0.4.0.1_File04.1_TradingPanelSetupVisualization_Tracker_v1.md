   from SetupDetectionMonitor (aggregation for display, no new Worker logic).

did not add that. The Setup Stats panel is fully wired for it already
(`failed_aborted` key exists end-to-end) - it will populate automatically the
day File 04 itself starts emitting an abort/recycle event, no UI change
