## What this fixes

Live chart showed a Bear pending chain drifting several candles away from
its original POI touch, through failed 3-candle attempts, without ever
touching the POI again. Root cause: the "recycle Candle2 and immediately
re-pair" logic never checked if the new incoming candle touched the POI -
only the very first entry into a chain required a touch.

## The fix

One condition added in `_step_waiting_c3()`: immediate re-pairing on
recycle now requires the incoming candle to have touched the POI. If not,
the chain aborts back to NONE instead of silently drifting. Nothing else
in the algorithm changed - same recycle target (Candle2), same confirm
logic, same everything else.
