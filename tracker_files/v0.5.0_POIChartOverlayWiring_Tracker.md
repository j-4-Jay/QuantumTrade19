## 2. Confirmed working (user-verified this session)
- **POI horizontal lines** (PDH/PDL, 4H/1H/15m/5m/1m High-Low, Week/Month) render at the correct price, with per-timeframe custom color, and a simplified "Prv. TF High/Low (price)" label.
- **Display vs Strategy are fully independent** — a POI now computes whenever either flag wants it, matching the locked 03.1 spec (fixed a real bug where Strategy=OFF silently blocked Display=ON).
- **Timezone Mode toggle** (NY auto-DST / UTC) correctly re-buckets PDH/PDL/4H/Week/Month boundaries using the 1H HTF series; 1m/5m/15m/1H are correctly unaffected (mathematically identical in both modes).

- **Previous-Period Start/End vertical markers** — merged into each TF's own card (Display/Strategy/Color/Vertical marker/Droplet/Style/Transparency all in one place), disabled until that TF's Display is ON.
- **Droplet wave dots** — a small animated marker at each line-POI's real formation candle, pixel-exact via klinecharts' documented `convertToPixel({dataIndex})`, tracks pan/zoom in real time via `subscribeAction` (zero polling cost).
- **Horizontal + vertical label overlap** — both now stack vertically with a clean gap when prices/times are close, ordered higher-timeframe-first; otherwise each label stays exactly at its own natural position.
- **Chart background** — Auto (follows app's current Yellow/Saffron/Blue/Lime × Day/Night theme) or an explicit override (all 8 themes + White + Black) via right-click → Change Mode.
- **Candle Style card** — Solid/Hollow/Up-Hollow/Down-Hollow body types (real klinecharts types) with independent fill/border/wick colors for Up and Down.
- **Crosshair settings** — color, style, thickness, on/off, all persisted.
- **POI Bulk Controls** (Trading Panel page) — Hide Extras / Show Extras (remembers exactly what was hidden) / Enable Default Strategy / Disable All Strategy — all scoped to what's actually on the chart, not blanket resets.
- **Day theme parity** — dropdowns, menus, inputs, and hover states now use the app's own theme colors and remain readable in both Day and Night.
- **Sidebar 3-stage collapse** (Full / Icons / Line) — consistent geometry across all 3 stages; Line stage is now one large clickable icon, not a thin sliver.
- **Settings persistence** — every control in every new card writes to the JSON-backed `SettingsPersistenceWorker` immediately and restores correctly on restart.

## 3. Root-cause fixes worth remembering (for future debugging)
- Reflex background-task handlers can never be `await`ed directly from another handler — must be `return`ed/`yield`ed as an event. (Caused a full-session crash earlier in this build.)
- `POIType` is a `str`-mixed `Enum` — calling `str()` on a member returns `"POIType.PDH"`, not `"PDH"`. Never wrap `poi.poi_type` in `str()`.
- klinecharts v10 `convertToPixel({dataIndex})` already returns a candle's pixel **center** — adding any extra half-width offset overshoots.
- `get_historical_candles(symbol, tf, N)`'s third argument is **days**, not candle count — a source of the critical zone-rendering crash.
